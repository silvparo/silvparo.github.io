# KOBOM – aktualisierte Website (2026)

Eine schlichte, zeitgemässe statische Website auf Basis der Navigationsstruktur von www.byzanz-straessle.ch.

## Inhalt

- `index.html`: HOME & AKTUELL
- `kobom.html`: KOBOM
- `dienstleistung.html`: DIENSTLEISTUNG
- `foto.html`: FOTO (neue Motive aus dem Reiseprospekt und Link zu bisherigen Galerien)
- `archiv.html`: ARCHIV
- `ueber-mich.html`: ÜBER MICH
- `foerderung.html`: FÖRDERUNG
- `dank-anerkennung.html`: DANK & ANERKENNUNG
- `kontakt.html`: KONTAKT
- `reisen-2027.html`: zusätzliche Detailseite zur Kulturstudienreise 2027
- `seminare-2026-27.html`: zusätzliche Detailseite zu Seminaren 2026/27
- `styles.css`: gemeinsames CSS (responsive)
- `script.js`: mobiles Navigationsmenü und E-Mail-Vorbereitung des Kontaktformulars
- `downloads/`: alle drei bereitgestellten Dokumente plus eine PDF-Fassung der Seminar-Einladung
- `assets/`: kleinere Bilder aus dem bereitgestellten Sizilien-Reiseprospekt und Favicon

## Lokale Ansicht

1. ZIP entpacken.
2. `index.html` in einem Browser öffnen.
3. Die Navigation führt zu den weiteren HTML-Seiten und Dokumenten.

Zur Publikation den **gesamten Ordnerinhalt** auf den Webserver hochladen. So bleiben alle relativen Links nutzbar. Kein Framework, keine Installation und keine externen Fonts nötig.

## Wichtige Hinweise

- Das Kontaktformular bereitet **nur** eine E-Mail vor (mailto), es versendet nichts automatisch.
- Die Seminare und Reisen wurden anhand der bereitgestellten Unterlagen 2026 und des bisherigen öffentlichen KOBOM-Auftritts redaktionell zusammengefasst. Termin-, Preis- und Programmänderungen sind möglich.
- Beim Seminar vom 10.10.2026 ist der auf der Einladung genannte Anmeldeschluss 05.10.2026 bereits verstrichen (Stand: 08.10.2026). Deshalb wird um eine direkte Nachfrage gebeten.
- Reiseprogramme 2028/29 sind als Vorhaben unter Vorbehalt gekennzeichnet.
- Die bisherigen Foto-Galerien und die älteren Archivdokumente verweisen auf die ursprüngliche Website; deren Inhalte wurden nicht kopiert.
- Die PDF der Seminar-Einladung wurde aus der bereitgestellten DOCX-Datei erzeugt. Zusätzlich liegt die DOCX-Datei unverändert bei.

Diese Website ist ein **Neuentwurf** und keine direkte Bearbeitung der live veröffentlichten WordPress-Website.
